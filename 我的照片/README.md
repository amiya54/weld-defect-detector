# 把焊缝照片放到这个文件夹

把你**脱敏后**的焊缝照片（jpg / png / bmp）上传到这个文件夹，提交后 GitHub 云端会自动检测，结果会生成在仓库根目录的 `results/报告.md`。

## 上传步骤（网页操作，不用装任何东西）

1. 在这个文件夹页面点 `Add file` → `Upload files`
2. 选择照片 → 拉到最下面 `Commit changes`
3. 等几分钟，回到仓库根目录，打开 `results/报告.md` 看结果

## ⚠️ 上传前必做：脱敏

仓库是公开的，上传前务必裁掉或打码：

- 船名、船东标识
- 分段号 / 船体编号
- 日期水印、拍摄地点
- 任何可识别具体船舶的信息

本工具只做缺陷初筛，检测结论须经人工复核确认。
